## 🆘 Troubleshooting Common Issues

### Image Quality Problems
- **Ensure high-resolution uploads** for best AI processing
- **Avoid over-processing** - multiple heavy filters can degrade quality
- **Check export settings** match your intended use

### Performance Issues
- **Clear browser cache** if the editor feels slow
- **Try smaller image files** if processing takes too long
- **Use desktop version** for complex editing sessions
